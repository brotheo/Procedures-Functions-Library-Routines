Teacher notes

Each challenge follows the same exam progression: scenario → write the subprogram → call it → trace/explain. Accept any logically equivalent pseudocode; Cambridge mark schemes reward correct logic over exact layout.

RANDOM: in Cambridge pseudocode RANDOM() returns a value between 0 and 1, so answers must scale, round and offset it (e.g. ROUND(RANDOM() * 19, 0) + 1 for 1–20).

Challenge 1

Student Score Calculator

8 marks
Focus: Function · parameters · RETURN · ROUND

A school records three test scores for each student. The final score is the average of the three scores.

The final score must be rounded to the nearest whole number.

Tasks

1.

Write a function called CalculateAverage with three parameters. The function should:

  • calculate the average;
  • round the average to 0 decimal places;
  • return the result.
[4]
Answer
FUNCTION CalculateAverage(Score1, Score2, Score3) RETURNS INTEGER
    DECLARE Average : REAL
    Average ← (Score1 + Score2 + Score3) / 3
    RETURN ROUND(Average, 0)
ENDFUNCTION
Mark points
  • Function header with name and three parameters
  • Correct sum divided by 3 (brackets required)
  • ROUND(…, 0) used correctly
  • Value returned with RETURN and ENDFUNCTION
2.

The following pseudocode is executed:

Score ← CalculateAverage(72, 85, 76)
OUTPUT Score

State the value output.

[1]
Answer

78 — (72 + 85 + 76) / 3 = 77.67, rounded to 78

3.

State whether the variable Average used inside the function is a local or global variable.

[1]
Answer

Local — it is declared inside the function and only exists while the function runs.

4.

Explain why CalculateAverage is a function.

[2]
Answer
Mark points
  • It returns a (single) value…
  • …to the calling statement, where it can be stored/used in an expression (e.g. assigned to Score)
Challenge 2

Cinema Ticket System

10 marks
Focus: Function vs procedure

A cinema sells three types of tickets.

TicketPrice
Child120
Student180
Adult250

A customer enters the number of each type of ticket purchased.

Tasks

1.

Write a function:

FUNCTION CalculateCost(Children, Students, Adults)

The function should calculate and return the total cost.

[4]
Answer
FUNCTION CalculateCost(Children, Students, Adults) RETURNS INTEGER
    DECLARE Total : INTEGER
    Total ← Children * 120 + Students * 180 + Adults * 250
    RETURN Total
ENDFUNCTION
Mark points
  • Children * 120
  • Students * 180
  • Adults * 250, all three added together
  • Total returned with RETURN
2.

The following statement is executed:

Total ← CalculateCost(2, 3, 1)

State the value stored in Total.

[1]
Answer

1030 — 240 + 540 + 250

3.

Write a procedure:

PROCEDURE DisplayCost(Name, Total)

The procedure should output the customer's name and total cost.

[3]
Answer
PROCEDURE DisplayCost(Name, Total)
    OUTPUT "Customer: ", Name
    OUTPUT "Total cost: ", Total
ENDPROCEDURE
Mark points
  • Correct header and ENDPROCEDURE
  • Outputs Name
  • Outputs Total
4.

Explain one difference between CalculateCost and DisplayCost.

[2]
Answer
Mark points
  • CalculateCost is a function that returns a value to the calling program…
  • …whereas DisplayCost is a procedure that does not return a value; it carries out an action (outputs)
Challenge 3

Journey Time

10 marks
Focus: DIV and MOD

A computer stores the duration of a journey in seconds. For example:

TotalSeconds ← 7385

The program must convert the value into hours, minutes and seconds.

Tasks

1.

Complete the pseudocode.

Hours ← TotalSeconds DIV ______

Remaining ← TotalSeconds MOD ______

Minutes ← Remaining DIV ______

Seconds ← Remaining MOD ______
[4]
Answer
Hours ← TotalSeconds DIV 3600
Remaining ← TotalSeconds MOD 3600
Minutes ← Remaining DIV 60
Seconds ← Remaining MOD 60
Mark points
  • 3600
  • 3600
  • 60
  • 60 (1 mark each)
2.

State the values of Hours, Minutes and Seconds when TotalSeconds ← 7385.

[3]
Answer

Hours = 2, Minutes = 3, Seconds = 5

Working: 7385 DIV 3600 = 2; 7385 MOD 3600 = 185; 185 DIV 60 = 3; 185 MOD 60 = 5

3.

Write a function:

FUNCTION GetMinutes(TotalSeconds)

The function should return only the number of complete minutes after the hours have been removed.

[3]
Answer
FUNCTION GetMinutes(TotalSeconds) RETURNS INTEGER
    DECLARE Remaining : INTEGER
    Remaining ← TotalSeconds MOD 3600
    RETURN Remaining DIV 60
ENDFUNCTION
Mark points
  • TotalSeconds MOD 3600 to remove the hours
  • DIV 60 on the remainder
  • Result returned

Challenge 5

Even or Odd Student ID

7 marks
Focus: MOD · Boolean return

A school wants to determine whether a student's ID number is even or odd.

Tasks

1.

Write a function:

FUNCTION IsEven(ID)

The function should return TRUE if the ID is even and FALSE if the ID is odd. You must use MOD.

[3]
Answer
FUNCTION IsEven(ID) RETURNS BOOLEAN
    IF ID MOD 2 = 0
        THEN
            RETURN TRUE
        ELSE
            RETURN FALSE
    ENDIF
ENDFUNCTION
Mark points
  • Condition ID MOD 2 = 0
  • Returns TRUE when even
  • Returns FALSE otherwise
  • Accept RETURN ID MOD 2 = 0
2.
Result ← IsEven(246)

State the value of Result.

[1]
Answer

TRUE

3.
Result ← IsEven(315)

State the value of Result.

[1]
Answer

FALSE

4.

Explain what the following expression checks:

ID MOD 2
[2]
Answer
Mark points
  • It gives the remainder when ID is divided by 2
  • A remainder of 0 means even; 1 means odd

Focus: Selection inside a function

A school uses the following grading system.

MarkGrade
80–100A
70–79B
60–69C
50–59D
0–49F

Tasks

1.

Write:

FUNCTION GetGrade(Mark)

The function should return the correct grade.

[5]
Answer
FUNCTION GetGrade(Mark) RETURNS CHAR
    IF Mark >= 80
        THEN
            RETURN 'A'
        ELSE
            IF Mark >= 70
                THEN
                    RETURN 'B'
                ELSE
                    IF Mark >= 60
                        THEN
                            RETURN 'C'
                        ELSE
                            IF Mark >= 50
                                THEN
                                    RETURN 'D'
                                ELSE
                                    RETURN 'F'
                            ENDIF
                    ENDIF
            ENDIF
    ENDIF
ENDFUNCTION
Mark points
  • Correct boundary for A (>= 80)
  • Correct boundary for B (>= 70)
  • Correct boundary for C (>= 60)
  • Correct boundary for D (>= 50)
  • F for all other marks, with grade returned (not output)
2.

Write a statement that calls the function for a student with a mark of 73. Store the returned value in Grade.

[1]
Answer
Grade ← GetGrade(73)
3.

State the value stored in Grade.

[1]
Answer

B

4.

Explain why GetGrade should return a value rather than simply output the grade.

[2]
Answer
Mark points
  • The returned grade can be stored/used again by the program (e.g. saved, counted, compared)
  • The function is more reusable/flexible because calculation is kept separate from output
Challenge 7

School Trip Cost

10 marks
Focus: Function · selection · ROUND

A school trip costs:

  • Transport: 500 baht
  • Food: 250 baht
  • Entrance fee: 300 baht

Students with a membership receive a 10% discount.

The final cost must be rounded to the nearest whole baht.

Tasks

1.

Write:

FUNCTION CalculateCost(Member)

The function should:

  • calculate the total cost;
  • apply the discount if Member is TRUE;
  • round the result;
  • return the final cost.
[6]
Answer
FUNCTION CalculateCost(Member) RETURNS INTEGER
    DECLARE Cost : REAL
    Cost ← 500 + 250 + 300
    IF Member = TRUE
        THEN
            Cost ← Cost * 0.9
    ENDIF
    RETURN ROUND(Cost, 0)
ENDFUNCTION
Mark points
  • Header with parameter Member
  • Total of 500 + 250 + 300 (1050)
  • IF checks Member
  • 10% discount applied (× 0.9 or − 10%)
  • ROUND(…, 0)
  • Final cost returned
2.

Write a statement that calculates the cost for a member and stores the result in Cost.

[1]
Answer
Cost ← CalculateCost(TRUE)
3.

State the value of Cost.

[2]
Answer

945

Mark points
  • Total 1050
  • × 0.9 = 945
4.

Identify the library routine used to round the final cost.

[1]
Answer

ROUND

Robot Battery

Focus: RANDOM · using a returned value

A robot starts with a battery level of 100%.

Each time the robot performs a task, it uses a random amount of battery between 5 and 15 units inclusive.

Tasks

1.

Write:

FUNCTION BatteryUsed()

The function should return a random value from 5 to 15 inclusive.

[2]
Answer
FUNCTION BatteryUsed() RETURNS INTEGER
    RETURN ROUND(RANDOM() * 10, 0) + 5
ENDFUNCTION
Mark points
  • RANDOM() scaled and rounded to give 11 whole values
  • Offset by 5 and returned (range 5–15)
2.

The main program contains:

Battery ← 100
Used ← BatteryUsed()
Battery ← Battery - Used

If Used is 12, state the new value of Battery.

[1]
Answer

88

3.

Write a selection statement that outputs "LOW BATTERY" when the battery is below 20.

[2]
Answer
IF Battery < 20
    THEN
        OUTPUT "LOW BATTERY"
ENDIF
Mark points
  • Condition Battery < 20
  • Correct OUTPUT inside the IF
4.

Explain why BatteryUsed is a function.

[1]
Answer
Mark points
  • It returns a value (the amount of battery used) to the calling program
Challenge 9

Sports Competition

13 marks
Focus: Full exam-style question

A school competition has three events:

  • Running
  • Swimming
  • Cycling

Each event produces a score from 0 to 100. The total score is calculated by adding the three scores.

A student passes if the total score is 200 or more.

Tasks

1.

Write:

FUNCTION CalculateTotal(Running, Swimming, Cycling)

The function should return the total score.

[3]
Answer
FUNCTION CalculateTotal(Running, Swimming, Cycling) RETURNS INTEGER
    DECLARE Total : INTEGER
    Total ← Running + Swimming + Cycling
    RETURN Total
ENDFUNCTION
Mark points
  • Correct header and ENDFUNCTION
  • Three scores added
  • Total returned
2.

Write:

FUNCTION IsPass(Total)

The function should return TRUE if the student passes and FALSE otherwise.

[3]
Answer
FUNCTION IsPass(Total) RETURNS BOOLEAN
    IF Total >= 200
        THEN
            RETURN TRUE
        ELSE
            RETURN FALSE
    ENDIF
ENDFUNCTION
Mark points
  • Condition Total >= 200 (not > 200)
  • Returns TRUE when passing
  • Returns FALSE otherwise
3.

The following statements are executed:

Total ← CalculateTotal(75, 82, 68)
Passed ← IsPass(Total)

State the values of Total and Passed.

[2]
Answer

Total = 225, Passed = TRUE

4.

Write:

PROCEDURE DisplayResult(Name, Total, Passed)

The procedure should output the student's name, total score and either "PASS" or "FAIL".

[4]
Answer
PROCEDURE DisplayResult(Name, Total, Passed)
    OUTPUT "Name: ", Name
    OUTPUT "Total score: ", Total
    IF Passed = TRUE
        THEN
            OUTPUT "PASS"
        ELSE
            OUTPUT "FAIL"
    ENDIF
ENDPROCEDURE
Mark points
  • Correct header and ENDPROCEDURE
  • Outputs name and total
  • IF tests Passed
  • Outputs "PASS" / "FAIL" correctly
5.

State one local variable used in either function.

[1]
Answer

Total (declared inside CalculateTotal). Accept a parameter such as Running, Swimming or Cycling.

Challenge 10

Arcade Game

14 marks
Focus: Master challenge — everything combined

An arcade game gives a player a starting score. The game then:

  1. generates a random bonus between 1 and 10;
  2. adds the bonus to the starting score;
  3. rounds the score to a whole number;
  4. checks whether the final score is even or odd.

Tasks

1.

Write:

FUNCTION CalculateScore(StartingScore)

The function should generate the random bonus, add it to the starting score and return the final score.

[4]
Answer
FUNCTION CalculateScore(StartingScore) RETURNS INTEGER
    DECLARE Bonus : INTEGER
    DECLARE FinalScore : REAL
    Bonus ← ROUND(RANDOM() * 9, 0) + 1
    FinalScore ← StartingScore + Bonus
    RETURN ROUND(FinalScore, 0)
ENDFUNCTION
Mark points
  • Random bonus in the range 1–10
  • Bonus added to StartingScore
  • Result rounded with ROUND(…, 0)
  • Final score returned
2.

Write:

FUNCTION IsEven(Score)

Use MOD to determine whether the score is even.

[3]
Answer
FUNCTION IsEven(Score) RETURNS BOOLEAN
    IF Score MOD 2 = 0
        THEN
            RETURN TRUE
        ELSE
            RETURN FALSE
    ENDIF
ENDFUNCTION
Mark points
  • Condition Score MOD 2 = 0
  • Returns TRUE when even
  • Returns FALSE otherwise
3.

Write:

PROCEDURE DisplayResult(Name, Score, Even)

The procedure should display:

  • the player's name;
  • the final score;
  • "EVEN" or "ODD".
[4]
Answer
PROCEDURE DisplayResult(Name, Score, Even)
    OUTPUT "Player: ", Name
    OUTPUT "Final score: ", Score
    IF Even = TRUE
        THEN
            OUTPUT "EVEN"
        ELSE
            OUTPUT "ODD"
    ENDIF
ENDPROCEDURE
Mark points
  • Correct header and ENDPROCEDURE
  • Outputs name and score
  • IF tests Even
  • Outputs "EVEN" / "ODD" correctly
4.

The main program contains:

INPUT Name
INPUT StartingScore

Score ← CalculateScore(StartingScore)
Even ← IsEven(Score)

DisplayResult(Name, Score, Even)

Explain the purpose of each subprogram.

[3]
Answer
SubprogramPurpose
CalculateScoreGenerates a random bonus (1–10), adds it to the starting score and returns the rounded final score
IsEvenChecks whether the score is divisible by 2 and returns TRUE (even) or FALSE (odd)
DisplayResultOutputs the player's name, final score and EVEN or ODD

  • 1 mark per correct purpose
