The five patterns

7 min

Every method has the same shape: initialise before the loop → update inside the loop → use the result after the loop.

➕ Totalling

Total ← 0Total ← Total + Item

🔢 Counting

Count ← 0IF cond THEN Count ← Count + 1

⬆️ Maximum

Max ← List[1]IF List[i] > Max THEN Max ← List[i]

⬇️ Minimum

Min ← List[1]IF List[i] < Min THEN Min ← List[i]

➗ Average

Total ÷ Countcalculated after the loop
Rule 1: Max/Min start from List[1] — never 0. (What if every value is negative?)
Rule 2: Paper 2 arrays start at index 1, and comparisons use = not ==.
Rule 3: Use real division / for an average, not DIV.
Try it: Run each worked example. Then change one value in the array and predict the new output before you press Run.

DECLARE Data : ARRAY[1:4] OF INTEGER
Data[1] ← 7
Data[2] ← 3
Data[3] ← 12
Data[4] ← 9
Max ← Data[1]
Total ← 0
FOR i ← 1 TO 4
   Total ← Total + Data[i]
   IF Data[i] > Max THEN
      Max ← Data[i]
   ENDIF
NEXT i
